# notes/ —— 素材层

这个目录**不发布**，随便写。它只服务于一件事：别让当天的想法丢掉。

## 每天怎么记

```bash
npm run note                  # 创建 notes/YYYY-MM-DD.md
npm run note -- 2026-11-09    # 补昨天的
```

只填三格就够，别在这儿追求文笔：

- **今天搞懂了什么**：一句一条，写结论，不用写推导
- **代码 / 踩坑**：报错原文直接贴，越脏越好
- **卡在哪**：描述现象，不用假装已经解决

## 两种喂法

| 方式 | 怎么做 | 适合 |
| --- | --- | --- |
| 写文件 | 自己填 `notes/日期.md`，然后跟 agent 说"整理今天的笔记" | 学习时随手记 |
| 直接说 | 在对话里贴代码和问题，说"记进书里" | 边学边聊 |

两种都能用。素材进 `notes/` 之后，合并成章是下一步的事。

## 什么时候合并

同一主题攒到 3～5 条，就可以合成一章：

1. **给秩序**：按「为什么需要它 → 怎么工作 → 怎么用」重排
2. **补例子**：素材里通常只有结论，成书必须有能跑的代码 + 预期输出
3. **删废话**：「我觉得」「大概」开头的，要么给证据，要么删掉

合并完在新章节的 frontmatter 里留个 `notes:` 字段，指回来源，方便以后核对：

```yaml
---
title: 第 1 章 语法地基
order: 1
notes: notes/2026-11-09.md, notes/2026-11-11.md
---
```
