# Go 入门到并发实战

> 语法两周能过完，真正花时间的是"Go 为什么这么做"和"并发到底怎么不出错"。

## 这本书讲什么

- **语法最小集**：类型、接口、错误处理、defer——够写第一个服务。
- **并发**：goroutine、channel、select、context 取消传播，配能复现的竞态例子。
- **工程**：包组织、go mod、测试与基准、性能剖析（pprof）。

## 不讲什么

| 内容 | 去哪本 |
| --- | --- |
| 通用编程概念（变量、循环、函数） | 《Python 上手到实战》 |
| 微服务架构方法论 | 不单独成书，散在各章 |
