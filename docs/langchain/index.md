# LangChain 应用开发

> 从"调通一次模型接口"到"做出一个能上线的 Agent"，中间那些文档里不写的东西。

## 这本书讲什么

- **基本形状**：流式输出、结构化输出、工具调用三步闭环，先跑通再谈框架。
- **Agent 循环**：ReAct 为什么能跑通，工具集怎么设计，上下文怎么不爆。
- **RAG**：切分、召回、重排、评估——哪一步在真正决定效果。
- **工程化**：超时、重试、并发、成本核算，以及怎么给 Agent 写测试。
