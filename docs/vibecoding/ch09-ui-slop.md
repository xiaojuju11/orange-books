# 第 9 章 AI 做的界面，为什么总差一点

> 不难看，但满眼是“AI 泔水味”：破解 AI Slop，用设计规范与 Impeccable Skill 注入灵魂。

## 为什么需要它

让 AI “帮我做一个现代、高端、大气的 SaaS 落地页”，半分钟后页面生成完成。

你打开一看：
- 熟悉的蓝紫渐变背景，居中漂浮着一行加粗大标题；
- 底部并排摆着三张半透明毛玻璃卡片，带着淡淡的发光阴影；
- 圆角极其平滑的悬浮胶囊按钮，配着泛滥的系统默认图标。

单看每一个按钮和组件，挑不出明显的排版毛病；但合在一块，一股扑面而来的“AI 塑料感” —— 业内称之为 **AI Slop（AI 泔水味）**。

精致，但千篇一律；好看，但毫无灵魂与品牌辨识度。用户扫一眼就能脱口而出：“这绝对是 AI 自动生成出来的模板”。

---

## 根因剖析：为什么 AI 总会产出 Slop？

大模型是在全球海量公开网页数据上训练出来的。当你给出的指令缺乏明确约束，只说“做一个好看的页面”时，**大模型在概率上的最优策略就是“取平均数”**：
- 它会挑选训练集中出现频次最高、最安全、最不容易被用户直接判负的组合：最常见的渐变、最通用的字体、最烂大街的居中卡片布局。

**平均数从来不丑，但平均数意味着彻底丧失了辨识度与态度。**

要打破模型的“平庸安全偏好”，就不能靠泛泛的审美叮嘱，而必须建立严密的**工程化设计约束与专业质检审查**。

## 两大破局利器：从黑名单到 Impeccable

### 利器一：建立高频 AI 特征黑名单

在提示词或项目 `AGENTS.md` 中，直接贴出明确的“负面提示（Negative Prompts）”，封堵模型的懒惰选择：

```text
【UI 设计负向黑名单（严禁出现）】
1. 严禁使用蓝紫渐变（#6366f1 到 #a855f7 系列）作为全屏背景或标题文字渐变！
2. 严禁滥用毛玻璃（backdrop-blur）与重度弥散发光阴影！
3. 严禁在视口中央平铺三张均等的半透明卡片！
4. 严禁使用毫无意义的纯色空心圆、发光小圆点当背景装饰！
5. 字体严格使用系统默认中英文无衬线字体，禁止随意引入花哨的第三方网络字体！
```

通过黑名单强行堵死“最安全的平均数”，AI 才会真正调动深度思考去寻找干净的布局方案。

---

### 利器二：引入工业级设计审查神器 —— Impeccable Skill

社区开源了一款专治 AI 审美平庸的重磅武器：**`Impeccable`**。

它总结提炼了 **46 种最具代表性的暴露 AI 痕迹的设计缺陷**（过度留白、层级失衡、配色过饱和、缺乏微交互等）。它能在 Agent 编辑前端文件后，通过 Hooks 自动对 CSS/组件进行深度扫描和严格纠偏，强迫 AI 遵循专业 UI 设计师的审美标准。

#### 安装与集成（兼容 Cursor、Claude Code、Codex、Cline）

只需一行命令即可在开发环境中一键安装：

```bash
# 全局安装 Impeccable 设计质检 Skill
npx skills install @impeccable/design
```

在你的前端项目根目录中进行初始化配置：

```bash
# 项目级初始化与 Hooks 注入
/impeccable init
```

一旦安装，AI 在写下任何 React / Vue / HTML 代码时，都会受到 Impeccable 的暗中监督，一旦使用了烂大街的 Slop 设计，就会被当场亮红灯打回重做！

## 落地实操：打造高级界面的三大法则

### 法则 1：每页只留一个主张，拒绝平权

AI 天生喜欢将所有元素做成相同的视觉重量。你必须在派活时明确区分主次：

```text
这个页面的唯一使命：就是让新用户输入手机号点击“立即体验”。
其他所有辅助信息（核心特性、合作伙伴 Logo、用户评价）全部降级为灰度辅色。
除主按钮之外，全屏任何其他元素严禁使用品牌主色（#ea580c）！
```

### 法则 2：先定 Design Tokens，压缩发挥空间

“做的高级一点”是形容词，AI 只能靠猜；给它具体的数值档位，它就只能在轨道上行驶：

```text
【设计 Tokens 规范】
- 页面底色：#FAFAF8（纯净微暖浅米），主卡片：#FFFFFF，边框：#E5E7EB
- 文字字阶：只允许使用 12px / 14px / 16px / 24px / 36px，严禁随意手写 18px、22px！
- 强调色：仅允许在核心 CTA 按钮使用 #EA580C，文字主色 #1F2937，次要文字 #6B7280
- 圆角标准：卡片统一 8px，标签胶囊 999px，输入框统一 6px
```

### 法则 3：给坐标系，不给形容词

告别“要有呼吸感”、“要克制”这类虚词，给它成熟一流的参考对象：

```text
参考 Linear 官方网站的排版哲学：
采用大面积的克制留白，文字使用深灰取代死黑，主色全屏仅出现一处，利用细微边框取代笨重阴影。
严禁照抄其排版结构，只学习其极简克制的气质。
```

## 真实翻车案例：改了七版依然是“同一个页面”

::: danger 翻车案例：形容词带来的循环鬼打墙
**现场**：开发者要求：“帮我做一个技术文档首页，要更极简、更大气一点。”AI 改了五版，除了把蓝紫渐变换成了青绿渐变、把圆角从 12px 改成 16px 外，版式骨架没有产生任何实质变化。  
**根因剖析**：每一轮给出的反馈全是主观形容词。模型只能在训练集的“大气极简”平均数周围做微小抖动。  
**解法**：果断切换为规则控制：“安装 Impeccable，开启严苛审查模式。全屏清空所有渐变，背景改为 #FFFFFF。导航栏只保留一个粗细为 1px 的底部灰色实线边框，左侧文字全部左对齐，去除所有卡片阴影。”  
三分钟后，第六版产出，页面瞬间脱胎换骨，呈现出如 Stripe 官网般的极简工业质感！
:::
