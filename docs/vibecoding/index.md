# Vibe Coding 实战

> 用 AI 写代码，难的不是让它写，是**让它写对、写少、并且你能验证**。

## 这本书讲什么

四个部分，一条闭环：

```text
① 基础认识    你和它的分工：怎么派活、怎么兜住它的错误率
② 上下文工程  它每次开机看到什么：AGENTS.md、会话生命周期
③ 验收闭环    怎么知道它做对了：机器闸门、眼睛、回归
④ 需求与设计  活从哪来：SDD、决策先行、界面为什么差一点
```

少任何一环，都会在别的地方加倍还回来：

- 只有 ①，你会写出"看起来不错但不敢上线"的代码；
- 只有 ③，你会变成专职修 bug 的验收员；
- 跳过 ④，前面全部白做——方向错了，越勤奋越浪费。

## 怎么读

- **只想知道怎么让 AI 别再乱写**：第 1、5 章。
- **代码总是不敢上线**：第 2、6、7 章，这三章是一套验收体系。
- **一个会话越干越乱**：第 3、4 章。
- **从零开始做一个功能**：第 8 章 → 第 1 章 → 第 6 章，按这个顺序走一遍完整流程。

## 阅读约定

- 每章开头一句话说清学完能干什么，结尾三问自测，答不上来别翻页。
- 代码和提示词都能直接复制，提示词里的场景按你自己的项目替换。
- 涉及具体工具的地方只讲能力分类（操作型 / 排查型 / 闸门），不绑定某个产品——工具会换，分类不会。
