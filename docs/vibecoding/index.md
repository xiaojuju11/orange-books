# Vibe Coding 实战

> "让 AI 写代码"谁都会，难的是写完之后你敢不敢上线。

## 这本书讲什么

- **任务拆解**：什么活适合交给 AI，什么活交给它会返工三次。
- **上下文供给**：怎么把项目背景、约束、既有风格喂进去，而不是每次从零解释。
- **验证纪律**：AI 写的代码怎么验——测试、类型、运行证据，缺一不可。
- **复盘**：哪些提示有效、哪些坑重复出现，沉淀成自己的套路。

## 不讲什么

| 内容 | 去哪本 |
| --- | --- |
| 具体语言的语法 | 各语言的书 |
| 模型原理与训练 | 不在这套书范围内 |
