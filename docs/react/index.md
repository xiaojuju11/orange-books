# React 深度进阶

> 不用"React 是声明式的"这类复读句，直接看 Fiber、Hooks 链表和渲染调度。

## 这本书讲什么

- **渲染机制**：render 与 commit 两阶段，state 变更到底触发了什么。
- **Hooks 的真相**：为什么会有闭包陷阱，依赖数组为什么骗人。
- **性能**：memo / useMemo / useCallback 各自的成本，什么时候启用是净亏。
- **工程化**：路由与数据加载、状态管理选型、类型推导。
