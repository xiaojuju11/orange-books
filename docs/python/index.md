# Python 上手到实战

> 一本按天长出来的书：每天学一点，当天进 `notes/`，攒够了合成一章。

## 这本书怎么长出来的

不是先写完大纲再动笔，而是反过来：

```
每天  notes/2026-11-09.md     ← 碎片：搞懂了什么、踩了什么坑
       ↓ 攒够 3～5 条同主题的
每周  docs/python/chNN-*.md   ← 合并成一章：给秩序、补例子、删废话
       ↓
每次  git push                ← 自动构建上线
```

所以这本书的章节顺序**跟着学习进度走**，不是跟着教科书的目录走。写到哪算哪，但每一章都要求是"能读懂的成品"，不是笔记堆。

## 怎么读

- **只想快点能写脚本**：第 0 章 → 第 1～4 章 → 第 9 章，够用了。
- **要维护别人的 Python 项目**：加上第 7、8、10、12 章。
- **想搞懂为什么**：第 5、6 章是分水岭，Python 的对象模型和 JS 差得比想象中远。

::: tip 给 JS / TS 开发者的加速器
你有 JS 底子，这本书里凡是能和 JS 对照的地方都会标出来（`npm` ↔ `uv`、原型链 ↔ MRO、`Promise` ↔ `asyncio`）。
但有一半结论**不能迁移**——绑定、可变性、真值判断、作用域规则都不一样，遇到标了 ⚠️ 的地方请停下来。
:::

## 阅读约定

- 代码块都标了 Python 版本要求，默认按 Python 3.12+ 写。
- 每个示例都能直接跑，跟一段预期输出；对不上说明环境有问题，不是示例有问题。
- 每章最后三问，答不上来就别急着翻页。
