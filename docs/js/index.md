# JavaScript 精讲

> 从"能写"到"能解释"的那一层：每个机制都问三遍——规范里怎么定义、运行时发生了什么、我怎么证明自己懂了。

## 这本书讲什么

- **语言机制**：执行上下文、闭包、this、原型链、事件循环。
- **手写实现**：Promise、防抖节流、深拷贝、发布订阅——用最小实现验证理解。
- **TypeScript 收口**：类型推导、泛型约束、`any` 与 `unknown` 的真实差别。
